# RoleClear Design Update

This version keeps the existing RoleClear visual direction while refining the UI:

- Green remains the primary brand/positive-action color.
- Blue is used for informational states, links, imported opportunity signals and email events.
- Orange is used for attention states, follow-ups and medium-priority signals.
- Red is used for rejection, high-risk, error and destructive states.
- Typography is less heavy: Inter is used for interface text and major headings/cards are reduced to semibold where appropriate.
- Semantic color is used selectively rather than making the whole interface colorful.
- Existing page structure and interactions are preserved.

## Run locally

```bash
npm install
npm run dev
```

Then open the localhost URL printed by Vite (normally `http://localhost:5173/`).

## Note

Dependencies are not bundled in this archive. Run `npm install` before starting the development server.
